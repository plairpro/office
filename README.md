# Офисная ярость

Быстрый браузерный PvP на 2–4 коллег. Каждый сам за себя: степлеры, швабры, настольные лампы и драка за кулер.
Без регистрации и без своего сервера — игроки соединяются напрямую (WebRTC), сайт лежит на GitHub Pages.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 — открой в двух окнах, чтобы проверить мультиплеер
npm run build        # сборка для GitHub Pages → dist/
npm run build:single # всё в одном HTML-файле → dist-single/index.html (открывается двойным кликом)
```

## Как играть

1. Введи имя и нажми **«Создать матч»** — появится комната с кодом.
2. **«Позвать коллег»** — ссылка уходит в рабочий чат (на телефоне откроется меню «Поделиться»).
3. Коллега открывает ссылку и сразу попадает в комнату. До 4 человек.

Управление: **WASD** — бег, **мышь** — взгляд. На телефоне — палец в любом месте экрана работает как стик.

## Устройство

| Папка | Что внутри |
|---|---|
| `src/config/game.ts` | Все параметры: скорость, камера, сеть, **оружие** (баланс правится только здесь) |
| `src/scene/` | Офис из примитивов. Вся статика склеена в 3 меша — 3 вызова отрисовки на весь офис |
| `src/game/` | Персонаж, анимация, движение со столкновениями, ввод (клавиатура, мышь, сенсорный стик) |
| `src/net/` | P2P-комнаты на [Trystero](https://github.com/dmotz/trystero): поиск друг друга через публичные Nostr-релеи, дальше — напрямую |
| `src/ui/` | Меню, HUD, приглашение по ссылке |

Сеть: каждый игрок рассылает своё положение 20 раз в секунду, чужих игроков сглаживаем и чуть экстраполируем по скорости.
Порядок входа в комнату определяет цвет и лифт появления.

## Графика и ассеты

Стилизованные модели — CC0-паки **KayKit** от Kay Lousberg (kaylousberg.com): мебель, кухня, модульные стены,
персонажи с 27 анимациями. Сборка паков: `node tools/build-assets.mjs <папка с клонами паков>` → `src/assets/*.glb`
(сжатие meshopt, всё вместе ≈2.4 МБ). Офисные персонажи — перекрашенные герои пака с аксессуарами на костях
(`src/game/avatar.ts`). Лицензии — `ASSETS_LICENSES.txt`.

## Карта и левел-дизайн

Этаж 28.8×25.9 м — компактно для 2–4 игроков: от респа до кулера 2–2.5 секунды бега.

- **«Вертушка» респов**: 4 лифта на 4 стенах со сдвигом (поворотная симметрия) — путь до кулера 13.7–14.4 м у всех.
  Порядок: 1-й и 2-й игроки появляются напротив друг друга, 3-й и 4-й — на свободных сторонах.
- **Карман респа**: стена перед лифтом и два выхода по 1.5+ м — с респа никого не видно, и тебя тоже.
- **Центр — «коробка»** вокруг кулера: экран, стеллаж, две кадки; 4 входа по диагоналям, у каждого респа свой.
- **Укрытия двух классов** (`SHOT_HEIGHT` в `src/scene/builder.ts`): выше 1 м — стены, стеллажи, капсулы, кусты —
  блокируют выстрелы; ниже — столы, пуфы, диваны — мешают только бегу.
- Зоны: переговорка, кабинет директора, рабочие зоны с акустическими перегородками, серверная, туалеты, кухня, лаунж.

**Анализ карты**: `npm run dev` → `/tools/analyze.html` — тепловая карта простреливаемости (дальность 10 м),
видимость между респами, пути от респов до кулера (поиск пути по сетке 0.5 м). Последний замер:
средняя простреливаемость 24% (было 47%), зона кулера 21% (было 61%), линий прострела длиннее 18 м — 137 (было 6769),
респы друг друга не видят.

`?overview` в адресе игры — общий план сверху.

## Публикация на GitHub Pages

В репозитории: **Settings → Pages → Source: GitHub Actions**. После каждого пуша в `main` сайт пересобирается сам
(`.github/workflows/deploy.yml`).
