# Офисная ярость

Быстрый браузерный PvP на 2–4 коллег. Каждый сам за себя: степлеры, швабры, настольные лампы и драка за кулер.
Без регистрации и без своего сервера — игроки соединяются напрямую (WebRTC), сайт лежит на GitHub Pages.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 — открой в двух окнах, чтобы проверить мультиплеер
npm run build        # сборка для GitHub Pages → dist/
npm run build:single # всё в одном HTML-файле → dist-single/index.html (открывается двойным кликом)
```

## Как играть

1. Введи имя и нажми **«Создать матч»** — появится комната с кодом.
2. **«Позвать коллег»** — ссылка уходит в рабочий чат (на телефоне откроется меню «Поделиться»).
3. Коллега открывает ссылку и сразу попадает в комнату. До 4 человек.

Управление: **WASD** — бег, **мышь** — взгляд. На телефоне — палец в любом месте экрана работает как стик.

## Устройство

| Папка | Что внутри |
|---|---|
| `src/config/game.ts` | Все параметры: скорость, камера, сеть, **оружие** (баланс правится только здесь) |
| `src/scene/` | Офис из примитивов. Вся статика склеена в 3 меша — 3 вызова отрисовки на весь офис |
| `src/game/` | Персонаж, анимация, движение со столкновениями, ввод (клавиатура, мышь, сенсорный стик) |
| `src/net/` | P2P-комнаты на [Trystero](https://github.com/dmotz/trystero): поиск друг друга через публичные Nostr-релеи, дальше — напрямую |
| `src/ui/` | Меню, HUD, приглашение по ссылке |

Сеть: каждый игрок рассылает своё положение 20 раз в секунду, чужих игроков сглаживаем и чуть экстраполируем по скорости.
Порядок входа в комнату определяет цвет и лифт появления.

## Карта

Open-space 36×28 м: переговорка со стеклянными стенами, серверная, кухня, 6 кластеров столов, перегородки-укрытия,
кулер в центре (зона режима «Кулер») и 4 лифта — по одному на игрока (точки появления и цели режима «Документы»).

## Публикация на GitHub Pages

В репозитории: **Settings → Pages → Source: GitHub Actions**. После каждого пуша в `main` сайт пересобирается сам
(`.github/workflows/deploy.yml`).
