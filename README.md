# Офисная ярость

Быстрый браузерный PvP на 2–4 коллег. Каждый сам за себя: степлеры, швабры, настольные лампы и драка за кулер.
Без регистрации и без своего сервера — игроки соединяются напрямую (WebRTC), сайт лежит на GitHub Pages.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173 — открой в двух окнах, чтобы проверить мультиплеер
npm run build        # сборка для GitHub Pages → dist/
npm run build:single # всё в одном HTML-файле → dist-single/index.html (открывается двойным кликом)
```

## Как играть

1. Введи имя и нажми **«Создать матч»** — появится комната с кодом.
2. **«Позвать коллег»** — ссылка уходит в рабочий чат (на телефоне откроется меню «Поделиться»).
3. Коллега открывает ссылку и сразу попадает в комнату. До 4 человек.

Управление: **WASD** — бег, **мышь** — прицел, **ЛКМ / пробел** — удар. На телефоне — палец в любом месте экрана работает
как стик, красная кнопка — удар с автоприцелом по ближайшему.

## Бой

Чем дальше бьёт оружие и чем сильнее его эффект — тем меньше урона в секунду и тем быстрее оно кончается.
Резак всегда в руке и бесконечный; всё подобранное — временное.

| Оружие | Где взять | Дальность | Конус | Урон × темп | Урон/с | Эффект | Запас |
|---|---|---|---|---|---|---|---|
| 🔪 Резак | всегда в руке | 0.45 м | 70° | 18 раз в 0.4 с | 45 | кровотечение 6 с, ×2 в спину | ∞ |
| 💡 Лампа | кабинет директора | 1 м | 90° | 5 раз в 1.2 с | 4 | оглушение 2 с (повторно — через 1.5 с) | 3 попадания |
| 🧹 Швабра | юг, у лаунжа | 2 м | 140° | 14 раз в 0.75 с | 19 | замедление 3 с, отбрасывает | 5 попаданий |
| 💸 Деньгомёт | юг, у теннисного стола | 5 м | веер 30° | 7 купюр по 2 раз в 0.9 с | 16 | выбивает оружие, 2 с нельзя бить | 6 выстрелов |
| 📎 Степлер | север, у отдела продаж | 10 м | 4° | 8 раз в 0.3 с | 27 | кровотечение 3 с | 12 выстрелов |
| ☕ Кофе | у переговорки и у кухни | — | — | +30 здоровья, останавливает кровь, ускорение 5 с |

Смерть — голова отдельно, фонтан и лужа, которая остаётся до конца раунда; через 3 секунды — лифт подальше от
соперников и 1.5 секунды неуязвимости. Победа — 10 убийств, потом новый раунд. Режим «Конфетти» (внизу справа) — для офиса.
Баланс — в `src/config/game.ts`; витрина моделей оружия — `/tools/weapons.html`.

Сеть: попадание считает тот, **в кого** попали (сервера нет, спорить некому). Атакующий рассылает «ударил/выстрелил»
с зерном разброса — снаряды у всех летят одинаково; жертва проверяет попадание у себя и рассылает урон и смерть.

## Персонажи

У каждого одна сильная и одна слабая сторона; «сила» (живучесть × скорость атаки) у всех ≈ 110.

| Персонаж | Здоровье | Бег | Скорость атаки | Особенность |
|---|---|---|---|---|
| Бухгалтер | 80 | +5% | +10% | уклоняется от 20% ударов |
| Босс | 130 | −8% | −15% | почти не отлетает (−70%), крупный хитбокс |
| Секретарь | 75 | 0 | +45% | самый хрупкий |
| Курьер | 95 | +15% | 0 | первым добегает до оружия и кофе |

## Устройство

| Папка | Что внутри |
|---|---|
| `src/config/game.ts` | Все параметры: скорость, камера, сеть, **оружие** (баланс правится только здесь) |
| `src/scene/` | Офис из примитивов. Вся статика склеена в 3 меша — 3 вызова отрисовки на весь офис |
| `src/game/` | Персонаж, анимация, движение со столкновениями, ввод (клавиатура, мышь, сенсорный стик) |
| `src/net/` | P2P-комнаты на [Trystero](https://github.com/dmotz/trystero): поиск друг друга через публичные Nostr-релеи, дальше — напрямую |
| `src/ui/` | Меню, HUD, приглашение по ссылке |

Сеть: каждый игрок рассылает своё положение 20 раз в секунду, чужих игроков сглаживаем и чуть экстраполируем по скорости.
Порядок входа в комнату определяет цвет и лифт появления.

## Графика и ассеты

Мебель, кухня, модульные стены — CC0-паки **KayKit** от Kay Lousberg (kaylousberg.com).
Сборка: `node tools/build-assets.mjs <папка с клонами паков>` → `src/assets/*.glb` (сжатие meshopt).

Персонажи — CC0-пак **Ultimate Animated Character Pack** от Quaternius (quaternius.com): босс — Suit_Male,
курьер — Casual_Male, бухгалтер — OldClassy_Female (без цилиндра), секретарь — Suit_Female. Сборка:
`node tools/build-office-chars.mjs <папка с распакованными паками>` → `src/assets/office_*.glb`
(без лишних анимаций, ≈0.35 МБ на всех). Одежда перекрашивается по материалам, цвет игрока —
на галстуке, кепке и бейдже (`src/game/avatar.ts`). Лицензии — `ASSETS_LICENSES.txt`.

## Карта и левел-дизайн

Этаж 28.8×25.9 м — компактно для 2–4 игроков: от респа до кулера 2–2.5 секунды бега.

- **«Вертушка» респов**: 4 лифта на 4 стенах со сдвигом (поворотная симметрия) — путь до кулера 13.7–14.4 м у всех.
  Порядок: 1-й и 2-й игроки появляются напротив друг друга, 3-й и 4-й — на свободных сторонах.
- **Карман респа**: стена перед лифтом и два выхода по 1.5+ м — с респа никого не видно, и тебя тоже.
- **Центр — «коробка»** вокруг кулера: экран, стеллаж, две кадки; 4 входа по диагоналям, у каждого респа свой.
- **Укрытия двух классов** (`SHOT_HEIGHT` в `src/scene/builder.ts`): выше 1 м — стены, стеллажи, капсулы, кусты —
  блокируют выстрелы; ниже — столы, пуфы, диваны — мешают только бегу.
- Зоны: переговорка, кабинет директора, рабочие зоны с акустическими перегородками, серверная, туалеты, кухня, лаунж.

**Анализ карты**: `npm run dev` → `/tools/analyze.html` — тепловая карта простреливаемости (дальность 10 м),
видимость между респами, пути от респов до кулера (поиск пути по сетке 0.5 м). Последний замер:
средняя простреливаемость 24% (было 47%), зона кулера 21% (было 61%), линий прострела длиннее 18 м — 137 (было 6769),
респы друг друга не видят.

`?overview` в адресе игры — общий план сверху.

## Публикация на GitHub Pages

В репозитории: **Settings → Pages → Source: GitHub Actions**. После каждого пуша в `main` сайт пересобирается сам
(`.github/workflows/deploy.yml`).
